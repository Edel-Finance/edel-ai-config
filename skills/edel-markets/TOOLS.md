# Edel PERPS public MCP tools

Generated by `.github/scripts/sync_public_tools.py` from the public
[MCP tools page](https://docs.edel.finance/developers/mcp/tools) and the live TestNet
`GET /openapi.json`. Do not edit by hand: the hourly `sync-public-tools` workflow rewrites it and
opens a pull request when either source changes.

Each tool calls only the REST operations beside it. Open the tool's row in
[CAPABILITIES.md](CAPABILITIES.md) for its scope and docs page, and the route description in the
live contract for its limits. "Not in the live TestNet contract yet" means the docs list the tool
but the TestNet venue does not serve its route today: treat it as unavailable there.
